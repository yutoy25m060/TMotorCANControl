## 設計判断と理由

ユーザーから「A-2（駆動方式の決定）を考え直したい」という依頼を受けた。既存のA-2の結論
（2026-08-07、`θ₀∈[-90°,90°]` なら単方向ワイヤー1本で十分）は**重力のみ・加速度ゼロの
準静的モデル**で `τ_gravity` の符号だけを見たものであり、以下4点が判断材料から漏れていた。

1. 慣性項（`τ_eff = τ_gravity − I·θ̈` の符号反転）
2. モーメントアーム `l5` の符号（実現可否は `T = τ_eff/l5 ≥ 0` なので分母も効く）
3. 可動域端でのたるみ（`τ_gravity → 0` で `T → 0`）
4. 8-1 が挙げていた「片側ワイヤー＋バネ」案が比較から漏れていたこと

### 実装方針

- **`wire_statics.py` を改変せず、`drive_modes.py` として拡張した**。`wire_statics` の
  仮想仕事による符号導出（`T = tau_external/l_moment_arm`）はそのまま活かし、
  運動方程式 `I·ddtheta = tau_external − T·l_moment_arm` に拡張して
  `T = (tau_external − I·ddtheta)/l_moment_arm` を得ている。`ddtheta=0` で `wire_statics` に
  一致することをテストで確認済み（`test_unidirectional_matches_wire_statics_in_static_limit`）。
  - **代替案として検討し却下**: `wire_statics.solve_wire_tension()` に `ddtheta` 引数を足す案。
    却下理由: `wire_statics` はフェーズC（準静的）の成果物として既にテスト済みであり、
    ドキュメント側も「フェーズE-1で動力学を足す」と役割分担している。準静的モジュールに
    動力学を混ぜると、フェーズC の検証結果がどこまで有効かが読み取れなくなる。
- **モーターのロータ慣性は関節の運動方程式に入れなかった**。ワイヤー駆動ではモーターが
  関節から離れて配置されるため、関節の受動的な運動方程式に反射慣性は直接現れない
  （ワイヤーを介してモーター側に効く）。`Mujoco/identification/` の同定値
  （armature 0.0127 kg·m² 等）は AK45-36 単体（アーム無し）の特性であって
  リンク慣性ではないので、混同しないよう docstring とドキュメントの両方に明記した。
- **リンク慣性は一様棒近似 `I = M·l1²/3 = 0.030` を採用**。点質量近似 `M·l_com² = 0.0225` は
  実リンクより小さく、単方向1本に有利すぎる（破綻周波数を楽観的に見積もる）ため。
- **拮抗の張力配分で実装バグを1件発見・修正した**。当初は「従動側を `T_min` に固定して
  主動側を解く」という素朴な配分にしていたが、これだと需要 `D` が 0 に近い区間で主動側の
  張力が `T_min` を下回る（`|l_b| < l_a` のとき顕著）。両側に `T_min` の下駄を履かせてから
  残差 `D' = D − T_min·(l_a+l_b)` を配分する形に改めた。この修正前は比較スクリプトが
  「拮抗2本＝成立する配置なし」という誤った結果を出していた。
- **比較スクリプトをリポジトリにコミットした**。第4部が「検証は使い捨てスクリプトで実施しており
  コミットしていない」と記録しており、実際それが原因で D-3 の掃引結果が誤ったまま
  長期間放置されていた（`.ai/logs/2026-08-13_08` 参照）。同じ轍を踏まないため、
  ドキュメント記載の数値は全て `a2_drive_mode_comparison.py` で再現できるようにした。

### 得られた結論（A-2 の判断を差し戻し）

- **最も効くのは慣性ではなく「モーター速度上限」だった**。ワイヤー繰り出し速度が
  `v = l5·θ̇` なので関節速度はドラム半径 `r_drum` に比例する。`V_max = 6.0 rad/s`
  （実機で裏取り済みの実測値）から、`r_drum < 42mm` では単方向1本が破綻する速度域に
  **物理的に到達できない**。つまり A-2 の答えは `r_drum` の選択と不可分であり、
  `r_drum` をフェーズE-2 に先送りしたままでは A-2 を確定できないことが判明した。
- **A-3 の `±90°` は単方向1本と原理的に両立しない**。端点で `τ_gravity=0` になるため
  任意の非ゼロ周波数で `T<0` が必要になる。加えて幅ちょうど180°では `l5→0` の特異点にも
  必ず触れる（グリッド探索で最良99.7%止まり、`±85°` なら100%）。
- **バネ案は却下**。準静的で単方向の2.3倍（69N vs 30N）の張力を要しながら 1.5Hz では
  結局破綻し、同じ周波数域で拮抗2本より張力が大きい（80.3N vs 53.1N）。
- **A-2 は「単方向1本で確定」から「暫定：単方向1本、目標揺動周波数の確定待ち」に差し戻した**。
  ~0.5Hz 以下なら単方向1本（可動域±80°以下）、0.75Hz 以上なら拮抗2本、という条件分岐で記載。

## 未対応・既知の課題

- **A-2 は確定していない（意図的に差し戻した）**。確定には以下4つの未定事項が要る:
  1. 脚の目標揺動周波数・振幅（歩容仕様）
  2. ドラム半径 `r_drum`（E-2 に先送りされていたが A-2 と不可分と判明）
  3. リンクの実慣性 `I`（現状は一様棒近似の仮値。CAD 由来の推定値でよい）
  4. 最低張力 `T_min`（現状 5N は実測根拠のない仮値）
- **A-3（可動域の仮決め）も要再考**。`±90°` 推奨という評価は上記2つの構造的問題を
  反映していない旨の注記は入れたが、可動域自体の再決定は未実施。
- 動作モデルは**正弦揺動1周期のみ**。実際の歩容は遊脚相・立脚相が非対称なので、
  歩容仕様が決まったらその軌道で再評価すべき。
- **関節側の摩擦・減衰を入れていない**。`Mujoco/identification/` の damping/frictionloss は
  AK45-36 単体の値であり関節軸受のものではないため使わなかった。実機の軸受が決まったら追加要。
- 拮抗2本の定滑車配置探索は「各ワイヤーを自分が主動になる区間だけで最適化してから合成評価」
  という近似（プリテンション由来の相互干渉を2次の効果として扱う）。厳密な同時最適化ではない。
- フェーズD（`pulley_placement_search.py`）は未着手のまま。A-2 が確定していないため、
  探索次元（2 or 4）が決まらず着手できない。
