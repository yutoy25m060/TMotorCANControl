# モデルベースデザイン・制御系設計のためのシステム同定入門

出典: MathWorks セミナー資料（Teja Muppirala, © 2012 The MathWorks, Inc.）。
元PDF: `モデルベースデザイン・制御系設計のため のシステム同定入門.pdf`。MATLAB System Identification Toolbox の入門解説。

## モデルベースデザインの前提

モデルベースデザイン（実行可能な仕様書 → シミュレーションによる設計 → コード生成による実装 → 連続したテスト・検証、のサイクル）は、
**正確なモデルがあることが大前提**。

## 動的システムのモデリング手法（2軸）

- **第一原理モデリング**（物理法則から導出）: Simulink, Simscape, SimMechanics, SimHydraulics, SimPowerSystems, SimDriveline, SimElectronics
- **データドリブンモデリング**（実測データから推定）: System Identification Toolbox, Neural Network Toolbox
- 中間: Simulink Design Optimization

## システムとモデルの基本概念

- 入力 `u`、出力 `y` を持つ実際のシステムに対し、状態空間モデル `x(t+1)=Ax(t)+Bu(t), y(t)=Cx(t)` などで近似する
- システムとモデルに同じ入力を与え、出力の**誤差を最小化**するようにモデルパラメータを調整する（最小二乗的アプローチ）

## モデル推定と評価の重要性

**推定と評価は分離する必要がある**: パラメータ数を増やせば学習データに対する誤差はゼロに収束してしまう（過学習）。
そのため、**別のデータセット（評価データ）でモデルを評価**しないと、モデルの汎化性能は判断できない。

- 学習データでの誤差は単調減少
- 評価データでの誤差はある点を境に増加に転じる（過学習の兆候）

## システム同定のワークフロー（4ステップ）

1. **入出力データの収集**
   - データ形式: サンプル時系列 (`IDDATA`) / 周波数領域データ (`IDFRD`)
   - "良い"入力信号が必要: サンプリング周波数がシステムに合っているか、入力がシステムを十分に励起しているか（`IDINPUT` で自動生成可）
   - 前処理: トレンド/DCオフセット除去 (`DETREND`)、異常値除去 (`MISDATA`)、ノイズ除去 (`IDFILT`)

2. **モデルの構造を選択**（最も難しい問題 — モデル構造で結果が大きく変わる）
   - 構造の種類: 伝達関数、状態空間、ARX、非線形ネットワークなど（`IDTF`, `IDSS`, `IDPROC`, `IDNLARX`, `IDNLHW`, `IDPOLY`, `IDGREY` 等）
   - 選び方は過去の経験と試行錯誤に依存

3. **その構造の最適なモデルを求める**（パラメータ推定）
   - `TFEST`, `SSEST`, `ARX`, `ARMAX`, `OE`, `PEM`, `NLARX` などで実行

4. **モデルを評価する**
   - シミュレーションで出力を確認 (`SIM`, `COMPARE`)
   - 残差・不確かさの解析 (`RESID`, `SIMSD`, `BODE`, `STEP`, `PZMAP`)

このプロセスは反復的（データ収集 → 構造選択 → 最適化 → 評価 → 必要なら前段に戻る）。

## 線形パラメトリックモデル

- **伝達関数**: `Y(z) = B(z)/F(z) · U(z)`（B-order: nb=ゼロ点数, F-order: nf=極数）
- **状態空間**: `x(t+1)=Ax(t)+Bu(t), y(t)=Cx(t)`（状態数 n）
- 両方とも入力uと出力yの間の線形微分方程式を表す手法

### 遅れ（delay）

入力に対して出力が反応するまでの時間を `nk` サンプルの遅れとしてモデル化:

```
状態空間: x(t+1) = Ax(t) + Bu(t-nk),  y(t) = Cx(t)
伝達関数: Y(z) = B(z)/F(z) · z^(-nk) · U(z)
```

線形パラメトリックモデルの構造は **極数 np、零点数 nz、遅れ nk** で定義される。

## 残差解析

残差 = シミュレーションの誤差（システム出力とモデル出力の差）。

**良いモデルは残差に相関がない**:
- 入力と残差の相互相関（Cross-correlation）: 良いモデルは全ラグで信頼区間（黄色帯）内に収まる
- 残差の自己相関（Auto-correlation）: 良いモデルはlag>0で急速にゼロに近づく

悪いモデルでは相互相関にピークが出たり、自己相関がゆっくり減衰したりする。

## ノンパラメトリック法

線形システムの特性を、パラメータを仮定せず曲線で完全に説明する手法。データから直接・簡単に推定でき、
モデル構造を決める前にシステムの基本特性を把握できる。

- **過渡応答**（インパルス応答・ステップ応答）: `IMPULSE`, `STEP`
- **周波数応答**: 線形システムに正弦波を入力すると同じ周波数の正弦波が出力される（振幅・位相のみ変化）→ ボード線図で表現 (`SPA`, `SPAFDR`, `ETFE`)

## モデルの不確かさ解析

推定されたモデルは外乱の影響で不確かさを持つ（他のデータセットを使えば推定結果が変わりうる）。
この不確かさは**信頼区間**として定量的に表示できる。

## モデル推定後の活用

- システムの挙動を理解し、様々な入力に対する応答をシミュレーション
- Simulinkにブロックとしてインポート可能（`IDDATA Source`, `Idmodel`, `IDDATA Sink`, `IDNLGREY/IDNLARX/IDNLHW MODEL` 等）
- 制御系設計に利用: Control System Toolbox, Simulink Control Design, Robust Control Toolbox, Model Predictive Control Toolbox, SISOTOOL
- 複雑なシステム（例: エンジンモデル）でも、Simulinkのシミュレーションデータを使ってSystem Identification Toolboxで同定可能

## AK45-36 との関連メモ

本資料はMATLAB/Simulinkエコシステム向けの解説だが、システム同定の**方法論・ワークフロー自体は MuJoCo sysid toolbox の使い方（[Mujoco_システム識別（SysID_モータ実機MuJoCo）について.md](Mujoco_システム識別（SysID_モータ実機MuJoCo）について.md) 参照）とも共通**:

- 学習データと評価データを分離する必要性（過学習対策）は、MuJoCo側での「別の検証用軌道でvalidationする」という手順と対応
- 残差解析の考え方（相関の有無でモデルの妥当性を判断）は、MuJoCo側の残差収束（52.7→0.036）の評価と同じ発想
- モデル構造選択の難しさは、MuJoCo側で「armature/frictionloss/dampingのどれを同定対象にするか」を絞り込む判断と対応する
