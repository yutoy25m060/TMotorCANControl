## 製品特徴 (Product Features)

AKシリーズモータードライバボードは、そのクラスにおいて中〜高性能なドライバチップを採用し、フィールド指向制御（Field Oriented Control, **FOC**）アルゴリズムと、速度・位置制御のための先進的なアクティブ外乱抑制制御（Active Disturbance Rejection Control, **ADRC**）技術を組み合わせている。

CubeMars Toolチューニングソフトウェアと連携し、パラメータ設定およびファームウェアのアップグレードが可能。

## 3. 製品寸法と取付上の注意 (Product Dimensions and Installation Notes)

**平面寸法（概要）**
- 全幅: 39mm
- 上部コネクタ間隔: 31mm
- 取付穴中心間隔: 11.5mm × 2箇所
- 取付穴径: Ø2.1mm
- 中央基準線からの距離: 16.5mm、20mm

**側面寸法（概要）**
- 高さ（コネクタ含む）: 11mm
- 基板厚み: 1.6mm

### 備考 (Remark)

1. 寸法公差: ±0.15mm／取付穴公差: +0.1mm / -0mm／PCB厚み公差: ±0.16mm。
2. 取付にはM2ネジの使用を推奨。
3. エンコーダマグネットとチップ間の推奨エアギャップ（AG）は1mm、最大でも3mmを超えないこと。
4. マグネット中心とチップ中心のずれ（偏心, DISP）の推奨最大値は0.3mm。

## 5. ドライバインジケーターランプの定義 (Driver Indicator Light Definitions)

基板上には3つのインジケーターランプがある：通信インジケーター（緑）、駆動故障インジケーター（赤）、電源インジケーター（青）。

| インジケーター | 状態 | 意味 |
|---|---|---|
| 電源インジケーターランプ（青） | 点灯 | ドライバボードに電源が供給されている |
| | 消灯 | ドライバボードに電源が供給されていない |
| 動作インジケーターランプ（緑） | 点灯 | モーターが動作中 |
| | 消灯 | モーターが動作していない |
| 駆動故障インジケーターランプ（赤） | 点灯 | ドライバボード故障 |
| | 消灯 | ドライバボード正常動作中 |

⚠️ **注意**: ドライバボードに電源投入後、青色ランプは正常状態では点灯し続ける。緑色・赤色ランプは起動時に2秒間点灯した後、消灯する。
