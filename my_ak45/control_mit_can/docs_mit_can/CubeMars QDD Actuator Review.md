# **「CubeMars」製QDDアクチュエータ徹底検証！3軸ロボットアームでバイラテラル制御も実施**

## **動画概要**

* **チャンネル名**: rough robotics  
* **公開日**: 2026年7月24日  
* **動画リンク**: [YouTube](https://youtu.be/ylL5EIASqEE)

## **1\. はじめに**

本動画は、CubeMars社から提供されたロボット用QDD（準ダイレクトドライブ）アクチュエータ「AKシリーズ（AK45-10 / AK45-36）」のV3モデルのレビューおよび動作検証を行っています。V3へのアップデートにより「デュアルエンコーダ」が搭載され、電源投入時に出力軸の角度を見失わないなど使い勝手が大幅に向上しています。

## **2\. QDD（Quasi-Direct Drive）とは**

高トルクモーターと低減速比のギアを組み合わせた構造です。

* **最大のメリット**: 良好な「バックドライバビリティ（逆駆動性）」。衝撃を吸収したり、バネのような柔らかい制御が可能。最近流行りのフィジカルAIとも相性が良いです。

## **3\. 機種ごとのスペックと特徴 (AK45-10 vs AK45-36)**

どちらも直径約50mmの小型サイズで、筐体はアルミ・黒アルマイトで高級感があります。

| スペック | AK45-10 | AK45-36 |
| :---- | :---- | :---- |
| **減速比** | 10 : 1 | 36 : 1 |
| **重量** | 約260g | 約350g |
| **厚み** | 45mm | 54mm |
| **定格トルク** | 2.5 Nm | 8 Nm |
| **最大(ピーク)トルク** | 7 Nm | 24 Nm |
| **最大回転数** | 180 rpm | 52 rpm |
| **逆駆動トルク** | 0.1 Nm (極めて良好) | 0.8 Nm (やや重い) |

### **バックドライバビリティについての考察**

減速比が36と大きい「AK45-36」は、手で回すとかなり重く感じます。これは減速比による抵抗の増加だけでなく、モーターの「慣性モーメント」が**減速比の2乗に比例**して出力軸に反映される（反射慣性）ためです。QDD本来の滑らかさを求めるならAK45-10の方が適しています。

## **4\. 動作確認と制御モード（シリアル通信）**

R-Link V3（USB変換機）を使用し、PCの設定アプリから動作させます。

電源は24V定格ですが、逆起電力によるエラーを防ぐため今回は16Vで安全に検証されました。

様々な制御モードが用意されています：

* **Trap Control (台形制御)**: 加減速ありの位置制御。  
* **Brake Mode**: コイルに電流を流して回転しにくくする（発熱に注意）。  
* **Position / Velocity / Current Mode**: それぞれ位置・速度・電流（≒トルク）を一定に保つモード。  
* **MIT Mode (インピーダンス制御)**: QDDの特性を最も活かせるモード。バネ定数(KpやKt)やダンパー(Kd)をリアルタイムに操作し、力加減を調整可能。

## **5\. CAN通信での動作**

M5AtomとミニCANモジュールを使用し、マイコンからの制御を実施。

* **メリット**: デイジーチェーン接続（数珠つなぎ）により配線を減らせる。ノイズ耐性が高い。  
* **注意点**:  
  1. CAN経由では基本設定（IDや通信速度など）の変更ができない（シリアル通信が必要）。  
  2. 終端抵抗が内蔵されているため、多数接続する場合は基盤から抵抗を外す加工が必要になる可能性がある。

## **6\. バイラテラル制御と3軸ロボットアーム検証**

最後に「リーダー（操縦側）」と「フォロワー（追従側）」を連動させ、力加減もフィードバックする**バイラテラル制御**を実装しました。

### **検証内容**

* **構成**: リーダー側に滑らかな「AK45-10」、フォロワー側に力持ちの「AK45-36」を使用。1軸でのテスト後、3軸ロボットアームを2機制作して連動。  
* **結果**:  
  * 障害物への接触や、ペットボトルの潰れ具合が手元（リーダー側）に伝わる。  
  * 力の増幅パラメータを設定することで、1kgのダンベルを軽い力で持ち上げることが可能。  
  * **改善点**: 3Dプリント部品（プラスチック）の剛性不足により力が逃げてしまうことと、リーダー側のコギング（カクつき）が操作の邪魔になる点。今後はリーダー側にダイレクトドライブ（DD）モーターの採用も検討。

## **7\. 今後の展望**

今回のQDDアクチュエータを活用し、今後は遠隔操作（テレオペレーション）や模倣学習を目的とした**6軸ロボットアームの制作**を予定しています。
